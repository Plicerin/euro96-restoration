# UEFA Euro 96 — Windows restoration

A non-commercial preservation and restoration project for Gremlin Interactive’s UEFA Euro 96 England. Original code, game assets, names and branding retain their respective ownership; this project claims no ownership of the original game.

[Play in your browser](https://plicerin.github.io/euro96-web/) · [Public restoration source](https://github.com/Plicerin/euro96-restoration) · [Public website repository](https://github.com/Plicerin/euro96-web) · [Preserved upstream source](https://github.com/videogamepreservation/actuasoccer96)

**Final restoration release: 0.70.0** — preserved as Git tag `v0.70.0-final`. This closes the agreed restoration scope. Future graphics or browser work is a separate project phase. [Final release record](docs/FINAL-RELEASE.md).

Windows 11 restoration of the preserved Euro 96 gameplay engine, with original Euro artwork and verified retail media. Current build: **0.70.0**, correcting the stadium board at the extra-time interval and restoring the country carousel's source-derived pace. Includes the verified Euro pass/rebound commentary, frontend fades and retail video boards. [Presentation evidence](docs/PERIOD-PRESENTATION.md), [closeout and remaining fidelity work](docs/RESTORATION-CLOSEOUT.md).

Use `../Play-Euro96.cmd` for the existing playtest installation. For a portable package, use `Start-Euro96.cmd`. Updates do not restart a running match. Existing Actua-named launcher aliases and save locations remain compatible.

Single-player matches and championships, CPU-versus-CPU, local two-controller head-to-head exhibitions, tactics/substitutions, save recovery, and saved replays are implemented. All 320 players have appearance/name coverage; all eight retail Euro venues and championship films are available. New championships follow the [original fixture venue schedule](docs/TOURNAMENT-VENUES.md); existing saves keep their selected venue.

Physical two-controller and audio-device checks remain a combined user test; automated checks do not certify those experiences. LAN/online play and co-op are outside this release's scope.
